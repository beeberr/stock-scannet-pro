# AGOR Creative Engineering — 17-stage project archive

**Purpose:** A durable GitHub record for the AGOR movable-pool-floor brochure/presentation project and all future decisions made for it in ChatGPT.

**Repository:** [beeberr/stock-scannet-pro](https://github.com/beeberr/stock-scannet-pro)  
**Archive path:** `new/AGOR-17-stages-archive/`  
**Branch:** `main`

## Archive rules
1. Record every user instruction, correction, approval, rejection, and decision that affects this project.
2. Save each selected image as a real file in `images/` before moving to the next stage. Record its stage number, source/credit, filename, and verification status in `image-register.md`.
3. Never mark an image as saved unless the file exists in GitHub and can be opened. A URL or search result is not a saved image.
4. Preserve the original order and full technical wording of all 17 stages. Do not merge or omit stages.
5. Record voice-message content as a transcript or faithful summary in the dated conversation log. Do not claim the original audio file is archived unless its audio bytes have actually been uploaded.
6. Keep a dated append-only log of new instructions and decisions. Update the index and relevant registers after each work session.
7. Keep unresolved items explicitly marked; do not invent approvals or fill gaps silently.

## Contents
- `project-brief.md` — project requirements and source-document facts.
- `stage-register.md` — canonical 17-stage list and technical content.
- `image-register.md` — selected image register and actual file verification.
- `decision-log.md` — durable decisions, corrections, and approvals.
- `conversation-log/2026-11-10.md` — initial archive request and working rules.
- `images/` — actual approved image files, one file per stage where possible.
- `recordings-transcripts/` — transcripts/summaries of voice instructions; original audio only when uploaded and verified.
