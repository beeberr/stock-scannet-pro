# Stock Scanner Pro

A Hebrew, right-to-left market research and paper-trading platform.

## Product goals
- Search stocks, ETFs, indices, currencies, commodities and crypto instruments.
- Separate spot and CFD paper-trading workflows.
- Provide technical setups and long-term value research with transparent scoring.
- Track forecasts and paper-trading performance over time.
- Clearly label data sources, timestamps, delays, fees, spreads and assumptions.
- Never imply guaranteed returns or place live-money orders.

## Development status
This repository is being rebuilt. The first release prioritizes a reliable dashboard, market-data resilience, watchlists, paper trading and an auditable forecast journal.
